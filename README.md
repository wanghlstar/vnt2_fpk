# VNT2 - 飞牛fpk安装包

- 支持 `x86_64` `arm64` `arm` `armv7` `armv5` 等架构，下载后在应用商店 手动上传安装即可，理论是支持所有架构的飞牛NAS安装的。
- `*_all.fpk`是新版本自动识别架构的安装包 `*_x86.fpk` `*_arm.fpk` 是旧版本无法识别全架构的安装包
- VNT2 与 1.x 不兼容，服务端和客户端都需要使用 2.x 版本
- 客户端首次安装后应用会保持"等待配置"状态（不会闪退），打开客户端会自动生成配置模板，取消 `network_code`/`server` 注释并填写后保存即自动启动组网
- `device_id` 为空时应用会自动生成并写入配置（服务端要求不能为空，且保持稳定）；`device_name` 留空则自动使用主机名
- `vnt2_cli` 异常退出（如注册失败、IP重复被服务端拒绝）时应用会自动重启（5秒间隔），不会再闪退，具体原因查看运行日志
- 自定义虚拟IP不要指定其他设备已使用的IP，否则服务端会拒绝注册(IP重复)，建议留空由服务端自动分配
- 服务端配置在安装时配置，后续需要修改 在 应用设置 修改后重启应用生效，首次启动会自动生成 config.toml，数据文件和日志在 文件管理 - 应用文件里
- 客户端只使用 `vnt2_cli`（命令行程序），未使用 `vnt2_web`
- 一代 VNT 的飞牛安装包在 [lmq8267/vnt_fpk](https://github.com/lmq8267/vnt_fpk) , 在线配置文件[生成](https://lmq8267.github.io/VntApp/)
- VNT2 项目地址：客户端 [vnt-dev/vnt](https://github.com/vnt-dev/vnt) 服务端 [vnt-dev/vnts](https://github.com/vnt-dev/vnts)

## 使用说明

### VNT2客户端

1. 安装后打开"VNT2-客户端"，状态显示"等待配置"，在配置文件里填写：
   - `network_code`：组网编号，相同编号的设备组同一个虚拟局域网
   - `server`：服务端地址，如 `["quic://101.35.230.139:6660"]`，公共服务端可直接使用
   - `password`：组网密码（可选，设置后节点间数据端到端加密，所有设备需保持一致）
2. 保存配置后自动启动组网，状态显示"运行中"即组网成功
3. 本机信息、设备列表、路由信息、运行日志均可在应用页面查看

### VNTS2服务端

1. 安装时在向导里配置：WEB管理端口(29871)、TCP服务端口(29872)、QUIC/UDP服务端口(29872)、虚拟网段(10.26.0.0/24)、WEB管理账号密码等
2. 首次启动会自动生成 `config.toml`（含中文注释）到数据目录，同时自动生成自签名 TLS 证书 `cert.pem` / `key.pem`
3. 路由器/防火墙需放行端口：`29872/TCP`+`29872/UDP`（客户端接入）、`29871/TCP`（Web管理），可选 `29873/UDP`（服务端互联）、`500/UDP`+`4500/UDP`（IKEv2）、`51820/UDP`（WireGuard）
4. 客户端使用 `quic://服务器IP:29872` 或 `tcp://服务器IP:29872` 作为服务端地址接入

## 目录结构

```
vnt2_fpk
├── .github
│   └── workflows
│       └── build.yml          # 打包工作流
├── vnt2                       # VNT2客户端安装包
│   ├── app
│   │   ├── bin                # vnt2_cli + vnt2_ctrl 各架构二进制
│   │   └── ui                 # 应用界面(配置管理页面)
│   ├── cmd                    # 安装/卸载/升级/启动等脚本
│   ├── config                 # 权限和资源共享配置
│   └── wizard                 # 卸载向导
└── vnts2                      # VNTS2服务端安装包
    ├── app
    │   ├── bin                # vnts2 各架构二进制
    │   └── ui                 # 应用界面(Web管理端入口)
    ├── cmd                    # 安装/卸载/升级/启动等脚本
    ├── config                 # 权限和资源共享配置
    └── wizard                 # 安装/配置/卸载向导
```
